# NavbatBor — Professional Online Booking va Elektron Navbat Platformasi

NavbatBor — O‘zbekistonda (Qarshi shahri) tibbiyot muassasalari, go‘zallik salonlari, avtoservislar va xizmat ko‘rsatish maskanlari uchun onlayn bron qilish va elektron navbat boshqaruvi tizimi.

## 🚀 Texnologiyalar
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express, TypeScript (esbuild)
- **Ma'lumotlar bazasi:** SQLite (`node:sqlite`)
- **Telegram Botlar:** 
  - Mijozlar boti: `@Navbat1Uzb_bot`
  - Biznes egalari boti: `@navbatbor_bizness_bot`

## 🛠 Ishga tushirish
1. Bog‘liqliklarni o‘rnatish:
   ```bash
   npm install
   ```
2. Loyihani yig‘ish va ishga tushirish:
   ```bash
   npm run build
   node dist/server.cjs
   ```
3. Sayt havolasi: `http://localhost:3000`
